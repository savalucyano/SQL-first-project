# Student Database Management System

## Project Overview

This project demonstrates the creation and management of a student database using SQL. It includes database creation, table definition, data insertion, updates, deletions, and various queries used to retrieve and analyze student information.

The project was created to practice fundamental SQL concepts and database operations.

## Features

### Database Creation

* Create a database named `student`
* Create a `student` table with appropriate fields and constraints

### Data Management

* Insert student records
* Update existing data
* Delete records
* Truncate table data

### Data Retrieval

* Display all student records
* Select specific columns
* Use aliases for improved readability
* Filter records using `WHERE` clauses

### Aggregate Functions

* Count total students
* Calculate average grades
* Count students by gender
* Group data and calculate averages

### Pattern Matching

* Search records using the `LIKE` operator

## Database Structure

| Column     | Data Type    | Description               |
| ---------- | ------------ | ------------------------- |
| student_id | INT          | Unique student identifier |
| last_name  | VARCHAR(20)  | Student's last name       |
| first_name | VARCHAR(20)  | Student's first name      |
| sex        | VARCHAR(1)   | Student gender (M/F)      |
| age        | INT          | Student age               |
| subject    | VARCHAR(20)  | Field of study            |
| average_g  | DECIMAL(3,1) | Average grade             |
